# IT 110 Flutter 

## Project Description
This project is a Flutter Web application developed for the IT 110 subject.It contains a Home Page and a Login Page.

## Features
- Home Page
- Login Page
- Basic client-side navigation

## Technologies Used
- Flutter
- Dart
- Visual Studio Code
- Google Chrome
- Git and GitHub

## Project Structure
- `lib/` — Main application code
- `web/` — Web-specific files
- `test/` — Test files
- `pubspec.yaml` — Project dependencies and configuration

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run `flutter pub get`.
4. Run `flutter run -d chrome`.

## Project Status
The Home Page and Login Page are running successfully in Chrome.
